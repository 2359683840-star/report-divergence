# 研报分歧探测器

## 一、问题发现

### 用户痛点

A股市场每天产出数百份分析师研报。对于普通投资者和初级分析师，存在三个明确痛点：

1. **信息过载**：一只热门股票可能有30+份近期研报，逐一阅读不现实
2. **观点矛盾**：不同券商对同一只股票评级相反（"买入" vs "减持"）很常见，但投资者难以快速定位"到底在吵什么"
3. **缺乏工具**：市场上没有工具专门做"研报分歧分析"——通用RAG回答"这只股票怎么样"，但不会告诉你"分析师们对这只股票的看法有多不一致"

### 竞品分析

| 竞品 | 做什么 | 不做什么 |
|------|--------|----------|
| 东方财富研报页 | 列出所有研报 | 不分析分歧 |
| 同花顺iFinD | 机构一致预期（平均值） | 抹平了分歧信息 |
| 通用AI问答（ChatGPT/Kimi） | 回答"这只股票怎么样" | 不量化分歧，无结构化对比 |
| 传统RAG系统 | 检索+生成回答 | 不做差异分析 |

**市场空白：分歧可视化。** 一致预期抹掉了最有价值的信息——不同机构在哪里打架。

## 二、产品设计

### 目标用户

- **主要用户**：关注基本面的A股中小投资者（需要快速判断"这只股票争议大不大"）
- **次要用户**：金融从业者（券商/基金研究员，需要快速对比同行观点）

### 核心价值主张

**一句话**：输入股票代码，三秒内看到分析师分歧的全景地图。

**差异化**：不是"AI告诉你答案"，而是"AI帮你看清争议在哪里"——信息透明 > 黑盒建议。

### 用户旅程

```
搜索股票 → 统计结果(3s) → AI预览自动触发(5-8s) → 点击"深度分析"(20-30s分步展示)
```

### 分歧地图五维度

1. **分歧分数（0-100）**：评级分布的标准差量化，一眼判断共识程度
2. **评级分布**：饼图展示多空比例
3. **机构对比**：哪家券商在唱多？哪家在唱空？
4. **关键假设冲突**：AI识别的核心变量分歧（行业增速、毛利率、市占率...）
5. **数据一致性**：不同研报引用的数据是否有出入

## 三、关键PM决策

### 决策1：先做统计，再做AI

**问题**：一上来就用AI分析，还是先做统计？

**决策**：Phase 1只做统计学分析（分歧分数、评级分布、机构对比）。Phase 2加AI语义分析。

**理由**：
- 统计学分析零延迟，3秒内出结果，保证核心体验不依赖API
- AI分析作为增强层而非基础层，即使AI挂了，产品仍有价值
- 降低MVP开发风险——先验证"分歧可视化"这个方向本身有没有价值

### 决策2：AI分析分步展示，不转圈

**问题**：AI分析需要20-30秒，用户体验怎么设计？

**方案对比**：
- A. 一个大转圈等30秒 — ❌ 用户不知道在等什么，流失率高
- B. 百分比进度条 — △ 比转圈好，但用户不知道"完成了什么"
- C. **每完成一个分析维度立即展示结果** — ✅ 等待变期待

**实现**：后端分4步调LLM（多空阵营→假设冲突→数据检查→总结），SSE流式推送到前端。用户看到分析结果逐步出现，不会焦虑。

### 决策3：搜索后自动触发AI预览

**问题**：AI分析是手动触发还是自动？

**决策**：步骤1（多空阵营识别）搜索后自动触发，步骤2-4用户点击触发。

**理由**：
- 步骤1结果（核心分歧+多空阵营）信息密度最高，自动展示给轻度用户提供即时价值
- 深度分析（假设冲突、数据一致性）适合需要做决策的用户主动探索
- 兼顾了"不想等待"和"需要深度"两类用户

### 决策4：数据源三级降级

**问题**：akshare爬取东方财富数据，网络不稳定经常挂。

**方案**：
1. 主路径：akshare实时拉取
2. 降级1：本地缓存JSON（预缓存10只热门股票）
3. 降级2：硬编码15只核心股票代码映射（保证搜索功能永远可用）

**UX处理**：使用缓存数据时UI顶部显示"缓存数据 (2026-07-29)"标签，保持透明。

### 决策5：技术选型 Next.js + FastAPI 而非纯 Python Streamlit

**问题**：用Streamlit（我会且快）还是Next.js（需要更多时间但品质高）？

**决策**：Next.js + FastAPI。

**理由**：对于AI PM作品集，视觉质感和产品体验是第一印象。Streamlit的"数据后台"视觉风格无法体现产品设计能力。Next.js提供完整的UI控制，FastAPI保证后端性能。

## 五、技术架构

```
用户浏览器 (Next.js + TypeScript + Tailwind + Recharts)
    │
    ├─ /api/analyze      → FastAPI (统计层: 3s)
    ├─ /api/analyze/ai/preview → FastAPI (AI预览: 5-8s)
    └─ /api/analyze/ai    → FastAPI (AI流式SSE: 20-30s)
                                    │
                            ┌───────┴───────┐
                            │               │
                        akshare        DeepSeek API
                     (东方财富实时)    (LLM分步分析)
                            │
                        cache/stock_cache.json
                     (10只热门股预缓存, 降级兜底)
```
